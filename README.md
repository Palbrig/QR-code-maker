# QR-code-maker
This is a very simple CMD program to create static QR codes from URLs. Run from CMD and input the URL you want a QR code of. QR codes are static and immutable, thus they're work indefinitley. 

Uses Python's QR library.

Open CMD, go to root folder, run program with:
python QRCode_Maker.py [enter url]
Then it will populate the folder with an svg file of the QR code
